# **Modelo 3D - OpenGL**

Este proyecto esta basado en la asignatura de Computación Grafica y en OpenGL, en este se hizo la carga de un modelo 3D a partir de GLTF y también se creo una curva de Bézier, se implementaron luces y una cámara, todo esto a partir de código en c++ y visual studio.

## Características
* Carga modelos 3D.
* Controles de cámara e iluminación.
* Curvas de Bézier

## Requisitos y ejecución
1. Clonar el repositorio.
2. Abrir la solución en Visual Studio y compilar el proyecto.
